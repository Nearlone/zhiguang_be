# RAG 扩展语料基线问题集

本题集用于测试知光的单篇知文 RAG。每篇包含直接事实题、机制完整性题和文档外拒答题，共 45 题。

## 测试约定

- 固定参数：`topK=5`、`maxTokens=1024`，一轮内不要调整参数。
- 每题新建独立会话，避免上一题的对话历史污染结果。
- 事实题和机制题应基于当前知文回答，并至少给出一个有效来源引用。
- 拒答题不应使用模型常识补全；只要当前知文没有依据，就应明确拒答。
- 记录总耗时、首 Token、召回切片、引用、Prompt Token、Completion Token 和异常状态。

## 评分方法

| 维度 | 分值 | 判定 |
| --- | ---: | --- |
| 关键点覆盖 | 0-2 | 0=未命中；1=部分命中；2=覆盖全部核心要点 |
| 事实忠实 | 0-2 | 0=明显编造；1=轻微越界；2=均可由当前知文支持 |
| 引用有效 | 0-1 | 事实/机制题引用可映射到召回切片；拒答题无需强制引用 |
| 行为正确 | 0-1 | 可回答题正常回答；文档外题明确拒答且不补充外部知识 |

单题满分 6 分。文档外题若未拒答，无论内容是否符合常识，行为正确记 0 分且标记为失败。
