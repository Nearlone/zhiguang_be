## 4. 数组 + 哈希

### 4.1 适用场景

- 快速查找某个值是否出现。
- 统计频率。
- 找两数关系。
- 去重。
- 前缀和。

### 4.2 高频题

- 两数之和。
- 字母异位词分组。
- 最长连续序列。
- 有效的字母异位词。
- 和为 K 的子数组。

### 4.3 模板：两数之和

思路：

```text
遍历数组，对每个 x 查 target - x 是否已经出现过。
```

Java 模板：

```java
Map<Integer, Integer> map = new HashMap<>();
for (int i = 0; i < nums.length; i++) {
    int need = target - nums[i];
    if (map.containsKey(need)) {
        return new int[]{map.get(need), i};
    }
    map.put(nums[i], i);
}
```

复杂度：

- 时间 O(n)。
- 空间 O(n)。

### 4.4 面试话术

```text
暴力两层循环是 O(n^2)。优化思路是用 HashMap 记录之前出现过的数和下标，遍历到当前数时只需要 O(1) 查询 target - 当前数是否存在，所以总时间 O(n)。
```

## 5. 双指针

### 5.1 适用场景

- 有序数组。
- 原地去重。
- 反转。
- 两端向中间收缩。
- 快慢指针。

### 5.2 高频题

- 移动零。
- 删除有序数组重复项。
- 盛最多水的容器。
- 三数之和。
- 反转字符串。

### 5.3 三数之和思路

步骤：

1. 排序。
2. 固定一个数 `i`。
3. 用左右指针找剩余两个数。
4. 跳过重复值。

复杂度：

- 排序 O(n log n)。
- 双指针 O(n^2)。

面试话术：

```text
三数之和先排序，然后固定第一个数，用左右指针找另外两个数。排序后可以根据 sum 大小移动指针，并且方便去重，整体复杂度 O(n^2)。
```

## 6. 滑动窗口

### 6.1 适用场景

- 连续子数组/子串。
- 最长/最短满足条件。
- 窗口内频率统计。

### 6.2 高频题

- 无重复字符的最长子串。
- 最小覆盖子串。
- 长度最小的子数组。
- 找到字符串中所有字母异位词。

### 6.3 模板

```java
int left = 0;
for (int right = 0; right < n; right++) {
    // 加入 right
    while (窗口不满足条件) {
        // 移除 left
        left++;
    }
    // 更新答案
}
```

### 6.4 最长无重复子串

思路：

- 用 Set 或 Map 维护窗口内字符。
- right 扩张。
- 出现重复时 left 收缩。

复杂度：

- 时间 O(n)。
- 空间 O(字符集大小)。

## 7. 链表

### 7.1 适用技巧

### 7.2 高频题

- 删除链表倒数第 N 个节点。

### 7.3 反转链表模板

```java
ListNode prev = null;
ListNode cur = head;
while (cur != null) {
    ListNode next = cur.next;
    cur.next = prev;
    prev = cur;
    cur = next;
}
return prev;
```

面试话术：

```text
用三个指针 prev、cur、next。每次先保存 next，再把 cur.next 指向 prev，然后 prev 和 cur 往后移动。最终 prev 就是新头节点。
```

### 7.4 删除倒数第 N 个节点

技巧：

- dummy。
- fast 先走 n 步。
- fast 和 slow 同时走。
- fast 到尾时 slow 在待删节点前一个。

### 9.1 核心遍历

### 9.2 高频题

- 二叉树最近公共祖先。

### 9.3 DFS 模板

```java
int dfs(TreeNode root) {
    if (root == null) return 0;
    int left = dfs(root.left);
    int right = dfs(root.right);
    return Math.max(left, right) + 1;
}
```

### 9.4 BFS 模板

```java
Queue<TreeNode> queue = new LinkedList<>();
queue.offer(root);
while (!queue.isEmpty()) {
    int size = queue.size();
    for (int i = 0; i < size; i++) {
        TreeNode node = queue.poll();
        if (node.left != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
}
```

## 10. 二分查找

### 10.1 适用场景

- 有序数组。
- 答案具有单调性。
- 查找边界。

### 10.2 基础模板

```java
int left = 0, right = nums.length - 1;
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (nums[mid] == target) return mid;
    if (nums[mid] < target) {
        left = mid + 1;
    } else {
        right = mid - 1;
    }
}
return -1;
```

### 10.3 高频题

- 二分查找。
- 搜索插入位置。
- 搜索旋转排序数组。
- 在排序数组中查找元素第一个和最后一个位置。
- 寻找峰值。
- x 的平方根。

### 10.4 面试话术

```text
二分的关键是有序或答案单调。写的时候我会明确区间定义，比如闭区间 [left, right]，循环条件就是 left <= right，更新时排除 mid。
```

## 11. 堆和 TopK

### 11.1 适用场景

- 找最大/最小 K 个。
- 数据流中位数。
- 合并 K 个有序链表。
- 高频元素。

### 11.2 Java PriorityQueue

默认小根堆：

```java
PriorityQueue<Integer> pq = new PriorityQueue<>();
```

大根堆：

```java
PriorityQueue<Integer> pq = new PriorityQueue<>((a, b) -> b - a);
```

注意 `b - a` 可能溢出，更稳：

```java
PriorityQueue<Integer> pq = new PriorityQueue<>((a, b) -> Integer.compare(b, a));
```

### 11.3 TopK 高频元素

思路：

1. HashMap 统计频率。
2. 小根堆维护 K 个最高频。

复杂度：

- 时间 O(n log k)。
- 空间 O(n)。

## 12. 回溯

### 12.1 适用场景

- 子集。
- 排列。
- 组合。
- 棋盘搜索。

### 12.2 模板

```java
void backtrack(路径, 选择列表) {
    if (满足结束条件) {
        记录答案;
        return;
    }
    for (选择 : 选择列表) {
        做选择;
        backtrack(路径, 新选择列表);
        撤销选择;
    }
}
```

### 12.3 高频题

- 子集。
- 组合。
- 括号生成。

面试话术：

```text

```

### 13.4 爬楼梯

定义：

```text
dp[i] 表示爬到第 i 阶的方法数。
```

转移：

```text
dp[i] = dp[i - 1] + dp[i - 2]
```

因为最后一步可以从 `i-1` 走 1 步，也可以从 `i-2` 走 2 步。

## 16. LRU 缓存

这是很高频的综合题。

要求：

- `get` O(1)。
- `put` O(1)。
- 超容量淘汰最久未使用。

思路：

```text
HashMap + 双向链表
```

- HashMap：key -> Node，O(1) 查找。
- 双向链表：维护访问顺序。
- 访问节点后移到头部。
- 超容量删除尾部。

Java 中也可以用 `LinkedHashMap` 简化，但面试常要求手写。

面试话术：

```text
LRU 需要 O(1) 查找和 O(1) 调整顺序，所以用 HashMap 定位节点，用双向链表维护最近使用顺序。get 后把节点移到头部，put 时如果超过容量就删除尾节点。
```

## 17. 算法面试常见追问

### 17.1 为什么用 HashMap？

```text
因为需要快速判断元素是否出现或快速查找下标，HashMap 平均 O(1)。
```

### 17.2 为什么先排序？

```text
排序后能使用双指针，也方便去重。
```

### 17.3 为什么用 dummy？

```text
dummy 可以统一处理删除头节点或插入头部的情况，减少边界判断。
```

### 17.4 为什么用 BFS？

```text
因为题目按层处理或要求最短路径，BFS 天然一层层扩展。
```

### 17.5 为什么用 DP？

```text
因为问题有重叠子问题和最优子结构，可以通过保存子问题结果避免重复计算。
```
